No model inference, phone latency or quality result is established by documentation or mocked contract tests. Provider response shape changes must fail closed, retain diagnostics without credentials, and require an adapter version bump. Hosted deployment must record provider model revision when supplied; if it is an unversioned alias, provenance says so and automatic long-lived cache reuse is disabled across a configured revision epoch.

Additional model-license evidence: Google's [BlazePose GHUM 3D model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20BlazePose%20GHUM%203D.pdf), page 2, explicitly identifies Apache License 2.0 for the Lite/Full/Heavy model family. This older model card also warns about distance, occlusion, orientation and metric-depth limitations. It is not evidence that current Tasks multi-person association works on climbing footage. Retain the exact downloaded task hash and the library/model notices in build records.
