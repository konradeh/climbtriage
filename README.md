# climbtriage

Android-first climbing analysis: track one selected climber, detect and edit holds and the route, and replay with aligned overlays.

This repository holds two independent implementations of the same first slice (M1), built from the same engineering brief:

| Folder | Built with | Start here |
|---|---|---|
| [`climbtriage-claude/`](climbtriage-claude/) | Claude Code | [`climbtriage-claude/README.md`](climbtriage-claude/README.md) |
| [`climbtriage-codex/`](climbtriage-codex/) | Codex | [`climbtriage-codex/README.md`](climbtriage-codex/README.md) |

Each folder is self-contained, with its own docs, Android app, backend, tests and setup instructions. Toolchains, virtual environments, build outputs, APKs and downloaded model files are not committed; each README explains how to recreate them.
